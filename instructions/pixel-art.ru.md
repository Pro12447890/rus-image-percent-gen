# Пиксель-арт: инструкция для ИИ (инструмент `pixel_art`)

Этот файл — единственная инструкция, которая нужна, чтобы нарисовать спрайт.
Инструмент вызывается так: `pixel_art` с полем `action`. Ниже — порядок работы,
правила и готовые рецепты.

## 1. Порядок работы

1. **Разрешение.** `action: "new"`, `width` и `height` — любое целое от 4 до 256.
   Холст создаётся пустым и полностью прозрачным (или залей `background`).
   Возьми минимальное разрешение, которого хватает замыслу: 16×16 — иконка,
   32×32 — мелкий спрайт, 64×64 — персонаж, 128×128 и больше — сцена.
2. **Рисование.** Три способа, их можно чередовать:
   - `pixels` — по одному пикселю: `{x, y, color, alpha?}`. Координаты с нуля,
     `(0,0)` — левый верхний угол. Цвет: `#rgb`, `#rrggbb`, `#rrggbbaa`,
     `"r,g,b[,a]"`, имя (`red`, `teal`, `skin`) или массив `[r,g,b,a]`.
     `alpha` — 0…255, где 0 — полностью прозрачный.
   - `draw` — ASCII-сетка плюс палитра. Компактнее всего для целого спрайта:
     ```json
     {"action":"draw","palette":{".":null,"K":"#1a1a1a","S":"#ffcd94","E":"#101820"},
      "rows":["..KKKK..",".KSSSSK.","KSESESK.","KSSSSSSK","..KKKK.."]}
     ```
     Ключ палитры — ровно один символ; символ, которого нет в палитре,
     **ничего не затирает** (удобно рисовать поверх); значение `null` — тоже
     «не рисовать». Все строки обязаны быть одной длины (добивай `.`).
   - `fill` — прямоугольник: `{x, y, w, h, color, alpha?}`. Без `w`/`h` —
     до края холста. Удобно для фона и крупных пятен.
3. **Посмотреть на себя.** `action: "preview"` возвращает холст картинкой PNG
   в увеличении ×5 (если сторона ≥ 128 — ×3, чтобы картинка не распухла).
   Смотри на неё как художник: силуэт читается? палитра не грязная? нет ли
   случайных одиночных пикселей? симметрия там, где нужна? Потом правь и
   смотри снова — сколько нужно, до результата.
4. **Мыслить без зрения.** `action: "dump"` возвращает сетку символов и легенду
   палитры. Это дешёвый способ проверить координаты, посчитать пиксели или
   сверить симметрию, не глядя на картинку.
5. **Итог.** `action: "save"` пишет PNG размером 1:1 (по умолчанию в
   `<рабочая папка>/pixel-art/<имя>-<W>x<H>.png`). Добавь `scale`, чтобы рядом
   лёг увеличенный файл — его удобно показывать человеку. Сохранённый файл и
   есть итоговая картинка: отдай его пользователю как результат.

## 2. Важные правила

- **Разрешение не меняется.** Холст создаётся один раз; `new` очищает его.
  Нужен другой размер — создай новый холст (можно с именем: `canvas`).
- **Никакого сглаживания.** Увеличение только целым множителем, каждый
  пиксель превращается в ровный квадрат — так и должно быть.
- **Альфа — это не полупрозрачная заливка «на глаз».** Полупрозрачность в
  пиксель-арте нужна редко: тени и дым лучше рисовать упорядоченным узором
  (дизерингом), а не размытием.
- **Координаты за холстом молча пропускаются.** Ответ инструмента скажет,
  сколько пикселей не поместилось — это подсказка, что фигура смещена.
- Лимиты вложений могут уменьшить увеличение предпросмотра. Тогда в тексте
  ответа появится объяснение — читай его, а не гадай, почему картинка мелкая.

## 3. Художественные рецепты

- **Силуэт раньше деталей.** Сначала залить форму одним тёмным цветом и
  посмотреть на превью: если силуэт не читается, детали не спасут.
- **Палитра 4–8 цветов.** Для каждого цвета — своя роль: тень, основа, свет.
  Меньше цветов — чище картинка. Классическая тройка: `#1a1a2e` (тень),
  `#e94560` (основа), `#f9d56e` (свет).
- **Свет — с одной стороны.** Выбери, откуда светит (обычно сверху-слева), и
  держись этого всю картинку.
- **Читаемость важнее анатомии.** У мелкого спрайта детали заменяются
  контрастом: тёмный контур, светлое пятно в центре, два цвета на объём.
- **Контур.** Тёмный контур по краю силуэта отделяет объект от фона; на 16×16
  он часто важнее самой формы.
- **Симметрия.** Рисуй половину в `rows` и повтори её зеркально — быстрее и
  ровнее, чем красить по пикселю.
- **Сетка и модуль.** На 32×32 удобно держать шаг 4 пикселя, на 16×16 — 2:
  форма получается «собранной», а не случайной.

## 4. Пример полного прохода

```json
{"action":"help"}                                   // прочитать это
{"action":"new","width":16,"height":16}             // холст
{"action":"fill","w":16,"h":16,"color":"#101820"}   // фон
{"action":"draw","palette":{".":null,"Y":"#f9d56e","O":"#e94560","K":"#1a1a2e"},
 "rows":["......YY......",".....YOOY.....","....YOOOOY....","...YOOOOOOY...",
         "...YOOOOOOY...","....YOOOOY....",".....YOOY.....","......YY......"]}
{"action":"preview"}                                // посмотреть
{"action":"pixels","pixels":[{"x":7,"y":14,"color":"#101820"},{"x":8,"y":14,"color":"#101820"}]}
{"action":"preview"}                                // проверить правку
{"action":"save","scale":5}                         // итог: файл 1:1 и файл ×5
```

## 5. Частые ошибки

| Симптом | Причина |
|---|---|
| Превью пустое | холст создан, но ничего не закрашено (все пиксели прозрачные) |
| Строки «разъезжаются» | в `rows` разная длина; добей строки символом из палитры или `.` |
| Цвет не тот | `#abc` — это 12-битный цвет; для точного бери `#rrggbb` |
| Правка «не видна» | вершина за пределами холста: проверь координаты через `dump` |
| Картинка мелкая в превью | сторона ≥ 128 → увеличение ×3, либо лимит вложений |
