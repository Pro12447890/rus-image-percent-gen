# История версий

## 1.5.0 — 19.10.2026
- **Предохранитель коротких сообщений**: если в поле меньше N букв (по умолчанию 5),
  перед отправкой появляется плашка «Точно ли вы хотите отправить?» — и не чаще раза
  в M минут (по умолчанию 5). Работает и для Enter, и для кнопки отправки; «Отправить»
  в плашке повторяет ровно то действие, которое человек только что сделал.
- **Копирование по правой кнопке**: правый клик по сообщению даёт меню
  «Копировать сообщение» / «Копировать всю переписку» — с ролями «Вы/ИИ», без кнопок
  действий и скрытых подсказок.
- **Тёмная тема по расписанию**: окно «с/до» по местному времени (может переходить
  через полночь) и плавный переход цвета, по умолчанию 10 секунд.
- Новая страница настроек «Улучшения» — все три ручки и их пороги.

## 1.4.0 — 17.10.2026
- Новая строка под полем ввода: **действующий тариф** — «Тариф: обычный» или
  «Тариф: пик ×2». Считается по системному времени пользователя: пик — пн–пт
  01:00–04:00 и 06:00–10:00 UTC, выходные всегда обычные. Обновляется каждые
  20 секунд, подсказка показывает окна пика в местном времени и момент смены.
- Слот `conversation.composer.dock` подключается необязательно: если DSH его не
  отдаёт, плагин работает без строки и не падает.

## 1.3.0 — 15.10.2026
- Переключатель прокси в подвале панели переведён на собственный движок:
  читает состояние у своего host-маршрута и переключает маршрут одним нажатием;
  кнопка видна всегда и сама подсказывает, если host-половина ещё не ответила.
- Новый маршрут `POST /api/rus-image-percent-gen/proxy/on` — включение по уже
  сохранённым настройкам (пароль не покидает host-половину).

## 1.2.0 — 15.10.2026
- Отдельная страница настроек прокси в интерфейсе (Настройки → Прокси): части
  адреса, включение, кандидаты, проверка по пингу со страной выхода.
- Поддержка SOCKS5 (`socks5://`, `socks://`, `socks5h://`).
- Настройки хранятся в файле профиля (`$DSH_HOME/rus-image-percent-gen.json`).

## 1.1.0 — 15.10.2026
- Один плагин вместо двух: русский интерфейс, масштаб элементов 80–220 %,
  инструмент `pixel_art` и выбор прокси в одном пакете.
- Ввод адреса прокси по частям, проверка кандидатов по пингу, страна выхода.

## 1.0.0 — 15.10.2026
- Первый выпуск: инструмент `pixel_art` (холст 4×4…256×256, покраска по пикселям,
  предпросмотр ×5/×3, экспорт PNG) и инструмент `proxy_switch`.
